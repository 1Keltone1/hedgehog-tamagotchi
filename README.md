# Ёжик-Тамагочи

Виртуальный питомец-ёжик в стиле пиксельных игр 2000-х.

## Функции
- 5 шкал: голод, радость, бодрость, чистота, здоровье
- Действия: поесть, поспать, помыться, полечиться, поиграть, охота
- 4 игры: боулинг, танцы, колесо, восьмёрка
- Магазин с предметами и баффами
- Несколько уровней с разными названиями
- Все действия сопровождаются гифками и звуками
- Сохранение прогресса в localStorage

## Запуск
Откройте `index.html` в браузере.

## Структура
- `index.html` — разметка
- `css/style.css` — стили
- `js/gifs.js` — ссылки на гифки
- `js/game.js` — состояние и логика времени
- `js/actions.js` — действия и игры
- `js/shop.js` — магазин
- `js/levels.js` — уровни
- `js/ui.js` — отрисовка и звук

## Технологии
HTML, CSS, JavaScript (без фреймворков).
